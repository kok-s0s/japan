# 🍣 日语 N1 词汇学习工具

> Launch first, polish later. 先发布，再打磨。

## 📖 开发背景

这个 repo 的诞生起因：年初报名了 7 月份的 N1 考试（**不合格** T_T），就做个玩意辅助学习日语。

截止目前为止的学习来看，很难听懂综艺节目，书写技能极差，口语表达也不行，纯看日语字幕的能力倒是还可。分数也和该自测一致...

现在学日语纯旅行游玩目的，其实学好英语在日本旅游还更便捷...
